## Classification legend used above
- **FINAL-ELIGIBLE**: none currently exist. No measurement in this project has been collected under the formal protocol (5 reps, validity gates, `run_id`, qdisc snapshot per run).
- **PILOT ONLY**: real observation, weak/partial provenance, useful for sanity-checking direction/order-of-magnitude, not for the thesis dataset.
- **PROVENANCE INSUFFICIENT**: asserted to exist but not locatable/reconstructable from currently-visible repository or conversation evidence.
- **SUPERSEDED**: not used in this table — no measurement here has been technically invalidated, only under-documented.
- **INCONSISTENT / RECHECK**: not used — no two measurements in this table directly contradict each other (they are all from different, incomparable conditions).
