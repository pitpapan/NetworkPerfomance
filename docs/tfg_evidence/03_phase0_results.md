Repetitions per cell are deliberately **blank**: `n` is `TBD FROM PILOT`, to be set from the noisiest pilot cell rather than assumed. `results.csv` (the per-run output file `collect_run_meta.sh` creates) does not exist in the repository and must be created by the first real run.

> The former 120-run figure (6 configs × 4 RTT × 5 reps, 24 cells) is **superseded**. It rested on treating `TCP_SND_QUEUELEN` and `MEMP_NUM_TCP_SEG` as experimental factors; 80 of those 120 runs were confirming a result already derivable from the compile-time constraints. See `08_design_rationale.md`.

**The one hard blocker remains the sampler.** A periodic, ACK-independent sampler must be designed and implemented to replace `tcp_poll` — see `02_experiment_history.md` Event 18. Under the mechanism-attribution framing this is not a supplement to the throughput measurement, it is the instrument that produces the *primary* evidence: without it there is no limiting-mechanism attribution and Phase 1 degrades to a throughput sweep. `collect_run_meta.sh` now enforces this by gating any run with `instr_sample_count == 0` as INVALID, so a sampler-less sweep cannot silently be recorded as data.
